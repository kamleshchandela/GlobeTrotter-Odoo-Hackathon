# GlobeTrotter - Hackathon Project

Welcome to the GlobeTrotter project! This is our hackathon MVP submission.

## Features
- AI Trip Generation
- User Authentication & Management
- Interactive Itinerary
- Discover and Save Gems
- Healthcare & Emergency Support

## Getting Started
### Prerequisites
- Node.js (v20 or higher)
- MongoDB

### Setup
1. Clone the repository
2. Install server dependencies: `cd server && npm install`
3. Install client dependencies: `cd client && npm install`
4. Setup `.env` files in both directories.
5. Start backend: `npm run dev` in `server`
6. Start frontend: `npm run dev` in `client`
